# Retail Sales SQL Analysis

## 📌 Project Overview

SQL data analysis project using a retail sales dataset to explore customer behavior, sales performance, product categories, and purchasing patterns using MYSQL.

The project demonstrates how SQL can be used to clean raw data, answer business questions, and generate actionable insights from transactional data.

## 🎯 Business Objective

Analyze retail sales data to understand:

* Overall sales and customer activity
* Sales performance by product category
* Customer purchasing behavior
* Gender and category-level transaction patterns
* Monthly sales performance
* Top customers by total sales
* Customer activity by time of day

## 🛠️ Tools & Technologies

* MySQL
* CTEs
* Aggregate Functions
* GROUP BY & ORDER BY
* CASE Statements
* Window Functions
* RANK()
* Data Cleaning

## 📂 Dataset

The dataset contains 2,000 retail transactions with 11 fields, including:

* Transaction ID
* Sale Date & Time
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Price per Unit
* COGS
* Total Sale

## 🔍 Analysis Performed

The SQL analysis includes:

1. Data quality and NULL-value checking
2. Total number of sales
3. Unique customer analysis
4. Product category analysis
5. Category-level sales and order performance
6. Average customer age by category
7. High-value transaction analysis
8. Sales analysis by gender and category
9. Best-selling month by year using `RANK()`
10. Top 5 customers by total sales
11. Unique customers by category
12. Sales by morning, afternoon, and evening shifts

The analysis demonstrates how SQL can transform transactional retail data into useful information for understanding sales trends, customer segments, product categories, and purchasing patterns.
